# بيان · Bayan

**منصة التحقق الشرعي بالدليل والدرجة** — أداة تثبّت صحة النص القرآني والحديثي من مصادره الأصلية، وتخريج الدرجة بأسماء أئمة الحديث، وتبيّن الخلاف دون افتئات، وتحيل ما يشتبه إلى أهل العلم.

مشروع فرد في **تحدي الذكاء الاصطناعي في خدمة المحتوى الإسلامي** (SDAIA · وزارة الاتصالات وتقنية المعلومات · Future Frontiers) ٢٠٢٦ — المسار ٠٤: أدوات المعرفة والتحقق لتمكين المعرّفين بالإسلام.

> **مبدأ المشروع:** لا تُعرض درجة ولا حكم إلا إن كان قابلًا للتتبع إلى مصدره. ما لا يكفِ فيه الدليل يُحال إلى أهل العلم، ولا يُملأ بالتخمين.

## ما الذي يفعله التطبيق

ثلاثة أوضاع، كلها بلا ذاكرة نموذجية: كل إجابة مبنية على نص موجود فعلًا في مصدر مُفهرس.

### ١. تحقّق الآية

مطابقة نصية آلية على نص المصحف بالرسم العثماني.

- **تطابق مؤكد** (١٠٠٪) · **مطابق مقارب** (كهرماني، ٧٠–٨٩٪) · **لم يُعثر على تطابق موثوق**
- إبراز الكلمات المطابقة **كلمةً كلمة** داخل النص الأصلي.
- إظهار **كل** المواضع المتكررة للآية (سورة الرحمن: ٣١ موضعًا) لا الموضع الأول فقط.
- قبول الاقتباس الجزئي والأخطاء المطبعية عبر نافذة منزلقة.
- ترجمة **Saheeh International** مع ذكر اسم الطبعة على البطاقة.
- **التفسير الميسر** (مجمع الملك فهد) عند الطلب، مُنسوبًا إلى مصدره.

### ٢. تخريج الحديث

- تجريد السند (الإسناد) تلقائيًا عند توفّر علاماته، ثم مطابقة المتن على المتون.
- عرض **كل** المخرجات من المجموعات السبع مع درجة كل مخرج **باسم مُصنِّفه**
  (العلي، الألباني، المرداوي وغيرهم).
- **إظهار الخلاف** بين الدرجات كما هو («اختلف علماء الحديث…») بدل ترجيحه.
- عند غياب حقل الدرجة في البيانات: «لا تتوفر درجة موثقة في مصدر البيانات» — ولا تُختلق درجة.
- إذا أدخل المستخدم سندًا لم يتحقق منه: تحذير «تمت المطابقة على المتن فقط».
- تمييز الكلمات الزائدة والناقصة في جملة نظيفة، لا بأحمر متقطع.

### ٣. اسأل بالدليل

سؤال بالعربية أو الإنجليزية، يُسترجع من **٤٠٬٤٣١ مستندًا مفهرسًا**، ثم يُصنَّف نوع الإجابة **حتميًا** (لا يُحكم النموذج):

| التصنيف | المعنى |
|---|---|
| **وُجد في المصادر** | مطابقة نصية فقط، لا حكم على الصحة |
| **نصوص ذات صلة** | سؤال في الحكم الشرعي: تُعرض النصوص، والفتوى لأهل العلم |
| **لم يتم العثور على تطابق موثوق** | الدليل لا يكفي — تُعرض إحالة أهل العلم |
| **حديث لا يصح** | ورد في القائمة المُنقّحة مع الحكم ورابط التحقق |

- استرجاع محلي فوري (< ١٠ مللي ثانية) يظهر **قبل** أي نداء خارجي.
- توسيع استعلام يعمل بالتوازي خارج المسار الحرج (مهلة ٦ ثوانٍ).
- ملخص مقيَّد بما استُرجع فقط — لا يُسأل النموذج عن معلومة خارج النصوص.

### ٤. الاستخراج من صورة (OCR)

استخراج نص من صورة آية أو حديث، ثم **يختبره** كإنتاج ضد الفهرس. لا يُقبل تلقائيًا: إن لم يطابق نصًا مُفهرسًا، يظهر التحذير ويُحال.

## التشغيل السريع

**المتطلبات:** Node.js ٢٠ أو أحدث، و `npm`. لا تحتاج قاعدة بيانات ولا خدمة خارجية.

```bash
git clone https://github.com/sokarnooo/Bayan-rebuilt-
cd Bayan-rebuilt-
npm install
cp .env.example .env      # ثم ضع مفتاحك (انظر القسم التالي)
npm run build             # يُنزّل الفهرس (~١٢٠ ميغابايت) مرّة واحدة
npm run dev               # http://localhost:3000
```

### ما يفعله `npm run build`

1. `tsx server/corpus/prebuild.ts` — ينزّل النصوص من المصادر المثبّتة على SHA محدّد ويولّد الفهرس المضغوط.
2. `vite build` — يبني واجهة الاستخدام (React + TypeScript + Tailwind).
3. `esbuild` — يحزم الخادم إلى `dist-server/server.js`.

**للتشغيل الإنتاجي:**

```bash
npm run start            # NODE_ENV=production node --expose-gc dist-server/server.js
```

**ملاحظات مهمة**

- الخادم **لا يستقبل الطلبات قبل تحميل الفهرس** (≈ ١٫٣ ثانية). نقطة `/api/health` تُظهر `ready:false` حتى تكتمل.
- بيانات الفهرس في `server/corpus/data/` مستثناة من Git (`.gitignore`) لأنها ضخمة؛ `npm run build` يعيد توليدها.
- المنفذ الافتراضي ٣٠٠٠، ويحترم متغيّر البيئة `PORT` إن حدّدته المنصّة.
- **للتحقق من سلامة الفهرس:** `curl http://localhost:3000/api/health`

## مفاتيح API المطلوبة

### `GEMINI_API_KEY` — مطلوب للوضعين «اسأل بالدليل» و «OCR»

| | |
|---|---|
| **من أين** | [Google AI Studio API keys](https://aistudio.google.com/apikey) — مفتاح مجاني |
| **لماذا** | توليد الملخص، وتوسيع الاستعلام، واستخراج النص من الصورة |
| **أين يُستخدم** | **الخادم فقط** (`process.env`). لا يُرسَل إلى المتصفح أبدًا |
| **بلا مفتاح** | **تعمل أوضاع التحقق كلها بشكل كامل.** «اسأل» يعرض النصوص المُسترجعة مع «تعذّر إنشاء الملخص الآلي الآن؛ النصوص أدناه هي المصدر»، وOCR يعطي رسالة خطأ واضحة |

> **بديل Bring-your-own-key:** من نافذة «الإعدادات» يمكن لصاحّب التطبيق إدخال مفتاحه الشخصي، فيتجاوز الحصة المخزّنة. يُرسل المفتاح من متصفح صاحب التطبيق إلى الخادم مباشرة ولا يُخزَّن.

### الصيغة

```bash
# .env
GEMINI_API_KEY=your_key_here
NODE_ENV=development
```

**قواعد أسرار ملزمة:**
- لا تضع `GEMINI_API_KEY` في أي متغيّر يبدأ بـ `VITE_` —Those تُحزَم داخل جافاسكربت المتصفح وتُسرَّب.
- لا ترفع `.env` إلى Git. الملف `gitignore` ويحوي `.env.example` كمرجع بلا قيمة.
- المفتاح يقرأ من الخادم فقط؛ لا تُمرّره في مَعلمات رابط ولا في نص برومبت.

### النماذج المستخدمة

| النموذج | الدور | RPD | حصة الساعة |
|---|---|---|---|
| `gemini-3.5-flash-lite` | الاستعلام والتلخيص واستخراج النص من صورة — الأول في كل السلاسل | ٥٠٠ | ١٦ |
| `gemini-3.1-flash-lite` | بديل عند ازدحام الأول | ٥٠٠ | ١٦ |
| `gemma-4-31b-it` | احتياطي أخير | ١٤٬٤٠٠ | ٤٨٠ |

> **النماذج لا تحكم.** كل نموذج مُتحقَّق منه في التوصيف فقط. الحكم في «اسأل» محسوب حتميًا من النصوص. لذلك تبقى قيمة النموذج في الملخص والصورة، لا في صحة النتيجة.

## كيف يعمل التطبيق

### مسار طلب التحقق

```
المستخدم يُدخل نصًّا
   ↓
تحطبيع عربي (شكل، همزات، تاء مربوطة، ألف مقصورة…)
   ↓
تجريد السند إن وُجدت علاماته  ──→  تحذير «مطابقة على المتن فقط»
   ↓
نافذة منزلقة: أفضل تداخل بين نصّ المستخدم ونص المصدر
   ↓
درجة تطابق + محاذاة كلمات (DP)
   ↓
عتبة: ≥٩٠٪ مؤكد · ٧٠–٨٩٪ مقارب · <٧٠٪ لا يُعرض
   ↓
عرض النتيجة + المصدر + الدرجة (أو «لا تتوفر درجة موثقة»)
```

### مسار «اسأل بالدليل»

```
سؤال (عربي أو إنجليزي)
   ↓
[فوري] استرجاع محلي من الفهرس المقلوب  ──→  بطاقات تظهر فورًا (< ١٠ مللي ث)
   ↓  (بالتوازي)
[٦ ث] توسيع استعلام بالنموذج ──→ إن غيّر الثلاثة الأولى: «تم تحسين النتائج»
   ↓
بناء بطاقات غنية لأفضل ٦ فقط (٤ أحاديث + ٢ آيات)
   ↓
[١٢ ث] تلخيص مقيَّد بما استُرجع (فشل → النصوص + رسالة بديلة)
   ↓
حكم حتمي على نوع الإجابة (مستقل عن الملخص)
```

### وضع الفشل الآمن

| الحالة | السلوك |
|---|---|
| نُفدت حصة النموذج | «اسأل» يعرض البطاقات + «تعذّر إنشاء الملخص الآلي الآن»؛ OCR يعرض رسالة قابلة للإغلاق |
| فشل النموذج | Failover للنموذج التالي في السلسلة |
| تعذّر الفهرس | الخادم لا يستقبل الطلبات، `ready:false` |
| الدليل غير كافٍ | **إحالة إلى أهل العلم** — لا جواب مُختلق |

## المطابقة والتحطبيع

التحطبيع يطبّق بالترتيب: تنظيف المسافات → ردّ الفارسية → ردّ الألف الخنجرية → إزالة التشكيل والتطويل → ردّ الهمزات والألف → ردّ التاء المربوطة → ردّ الياء (ى/ي) → توحيد الألف المقصورة والمنقوصة.

في **صيغة المطابقة** يُحذف الألف والهمزة والتاء المربوطة، فلا يفصل اختلاف الرسم الناقص بين مصدرَين للنص نفسه.

**درجات التشابه**

| الحالة | الدرجة |
|---|---|
| تطابق تام | ١٠٠٪ |
| اختلاف الهمزة/الألف | ١٠٠٪ |
| الألف الخنجرية في المصدر | ≈ ٩٦٪ |
| تطابق بالثابت وحده | خصم ٤٠ نقطة |

**عتبة العرض:** أدنى ٧٠٪ لعرض أي نتيجة. ما دون ٩٠٪ أو أي كلمة تقديرية يُوسَم **مطابق مقارب** بالكهرماني — لا «مؤكد».

## نظام الحكم في «اسأل بالدليل»

الحكم **حتمي بالكامل**: لا يُنتجه النموذج. يُحسب من النصوص المُسترجعة، فتتكرر النتيجة نفسها بالنص نفسه في كل تشغيل.

يستند إلى قياسَين مستقلَّين يجب أن يتّفقا:

1. **تغطية المفردات** — تداخل حقيبة الكلمات، متسامح مع البادئات.
2. **تغطية المحاذاة** — محاذاة الكلمات (DP) المشتقة من مدوّنة الأحاديث، حسّاسة للترتيب.

وقبل القياس تُحذف من السؤال **أدوات التأطير** (أدوات الاستفهام وأفعال النقل وعبارات الحكم) لأن «هل ورد أن النبي نهى عن…؟» لا يحمل محتوى بذاته.

الادعاء لا يُصنَّف «مؤيَّد» إلا إذا ارتفعت القياسان معًا. سؤال يُعيد استخدام مفردات حقيقية من الفهرس مع ادعاء مختلف (رقم، أو أجر، أو إذن) يفشل في أحد القياسين، فيُحال.

**هذا مُختبَر لا مُدَّعى:** مجموعة `ask_adversarial` (٢٠ سؤالًا خصوميًا) تتحقق أن **صفرًا** منها يُصنَّف «مؤيَّد».

## إدارة الحصة (Rate limiting)

- Hourly buckets على ساعة **America/Los_Angeles** مع عامل أمان ٠٫٨: `hourlyBudget = floor(RPD × 0.8 / 24)`.
- **Failover** بين النماذج الثلاثة بالترتيب عند 429/503.
- **حد لكل IP**posts，防止 استنزاف الحصة من عنوان واحد: `max(2, floor(0.2 × مجموع حصص الساعة))` مع حارس ١٠ طلبات/دقيقة.
- عند نفاد الحصة: 429 مع `retryAfterSeconds` ولافتة عربية قابلة للإغلاق.
- العدّادات في الذاكرة، وتبدأ عند ٥٠٪ بعد إعادة التشغيل كي لا تُستهلك الحصة كاملة في أول ساعة.
- **أوضاع التحقق لا تستهلك حصة إطلاقًا** — بلا نداءات خارجية.

## الاختبار الآلي

```bash
# شغّل الخادم أولًا على المنفذ ٣٠٠٠
npx tsx eval/run.ts http://localhost:3000 --quiet --runs 1
```

خيارات: `--only <suite>` لمجموعة واحدة · `--runs N` للتكرار · `--concurrency N` للتوازي.

**النتيجة المُقاسة** (`--quiet --runs 1`، ١٨١ حالة):

| المجموعة | حالات | النتيجة |
|---|---|---|
| التطابق الأساسي (آية/حديث) | ١٣٣ | **١٣٣/١٣٣ (١٠٠٪)** |
| توافق المخرجات والدرجات | ٦ | **٦/٦ (١٠٠٪)** |
| الحالات السالبة | ٤٧ | **٤٧/٤٧ (١٠٠٪)** |
| الصلة والاستطراد | ٢٨ | ٢٤/٢٨ (٨٦٪) |
| الأسئلة الخصومية | ٢٠ | **٢٠/٢٠ (١٠٠٪)** |
| **الإجمالي** | **١٨١** | **١٧٧/١٨١ (٩٨٪)** |

**الحالات الأربع المتبقية** كلها في «الصلة»:

## المعروف الحدود

مذكور صراحةً، لأن مصداقية الأداة تعتمد على وضوح ما لا تفعله:

- **مطابقة نصية لا حكم على الصحة.** وجود النص في مصدر مُفهرس لا يعني صحته بإطلاق.
- **السند لا يُحكم عليه من المتن.** إن أدخل المستخدم سندًا، يُطابَق المتن ويُعلَن ذلك.
- **لا تُستخدم ذاكرة النموذج.** كل درجة من حقل في بيانات مُجلوبة.
- **لا فتوى فردية.** المسائل الشخصية تُحال إلى أهل العلم.
- **الأداة ليست بديلاً عن أهل العلم.** نص ثابت أسفل كل صفحة.
- **٤ حالات من ٢٨** في مجموعة الصلة لم تُحسم (انظر الجدول أعلاه).
- **قائمة الأحاديث الموضوعة مُنقّحة يدويًا وهي صغيرة.** لا تُضاف مدخلات إلا بمراجعة يدوية ورابط تحقق.
- **التفسير الميسّر** مقتطف مختار آليًا من نص التفسير الكامل، لا تفسير كامل.
- **OCR** يلتقط النص ثم يختبره كمصدر مُفهرس؛ لا يُثبت صحة حديث من مجرد وجوده في صورة.

## English summary

**Bayan** verifies Qur'anic verses and hadith against their primary sources for AI Challenge 2026, track 04 (knowledge and verification tools).

- **Deterministic, not generative.** Matching and grading are computed from an indexed corpus. The language model only writes summaries and reads images — it never decides whether a text is authentic. The same input always yields the same verdict.
- **34,195 hadith** across 7 collections (Bukhari, Muslim, Abu Dawud, Tirmidhi, Nasa'i, Ibn Majah, النووي-٤٠) with per-narrator grades shown by name; **6,236 ayat** in Uthmani script with Saheeh International translation and Al-Muyassar tafsir.
- **Every grade is traceable** to a field in fetched data. No grade in the data means «لا تتوفر درجة موثقة» — never an invented ruling.
- **Escalation is never removed.** Below the evidence threshold the tool refers the user to qualified scholars instead of guessing.
- **Automated evaluation: 177/181 cases (98%)**, including 20/20 on adversarial questions that reuse real corpus vocabulary but assert a false claim — all correctly refused.

See [DEVLOG.md](DEVLOG.md) for the full change history and [ASK_DESIGN.md](ASK_DESIGN.md) for the retrieval design rationale.
